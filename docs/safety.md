# 使用边界与安全说明

本项目包含语音克隆、语音合成与多模态生成能力。部署或分享前请阅读本页。

## 音色克隆的授权确认

Web 界面（`apps/web`）的音色克隆有以下约束，均在服务端强制执行，前端只是展示：

- **必须授权确认**：`POST /clone_voice` 要求请求体包含 `consent: true` 与当前的 `consent_version`，缺少或版本不一致一律返回 `403`，不会读取或处理录音。
- **条款由服务端提供**：`GET /clone_consent` 返回当前版本号与条款文本（定义于 `apps/web/consent.py`）。修改条款时请同步提升 `CONSENT_VERSION`，使旧页面的确认失效。
- **只允许声音本人或已获授权者**：条款要求录音者本人，或已获得明确授权。项目不做身份核验，这一点由使用者负责。

## 审计日志

每次克隆成功、克隆被拒绝、删除音色都会向审计日志追加一行 JSON：

```json
{"ts": "2026-10-15T08:00:00+00:00", "event": "clone_created", "client": "127.0.0.1", "voice": "小王", "consent_version": "2026-10-v1", "audio_sha256": "..."}
```

- 默认路径为 `out/audit/voice_clone.jsonl`，可用环境变量 `BAIZE_AUDIT_LOG` 指定其他位置。
- 日志只记录哈希与元数据，**不保存录音本身**。录音的原始数据不落盘，只有提取后的 `voice_clone.pt`（speaker embedding 与 Mimi ref codes）保存在 `assets/speaker/`。
- 写入失败只会打印到标准错误，不会中断克隆流程；生产部署请监控该输出。

## 不应做的用途

- 未经同意克隆他人声音，或冒充他人进行欺诈、骗取钱财或身份认证。
- 生成误导性的音频、图像或视频，尤其是用于虚假新闻或政治宣传。
- 去除或绕过上述确认流程（例如直接调用接口而不经界面）。

## 部署建议

- Web 服务默认仅面向本地网络。若需对外开放，请放在带身份认证的反向代理之后，因为 `/clone_voice` 与 `/delete_voice` 不做用户鉴权。
- 定期检查审计日志，并依据使用者的要求删除对应的 `voice_clone.pt` 条目（界面的删除按钮会写入 `clone_deleted` 记录）。
- 语音输出建议在界面或下游产品中标注为 AI 生成。
